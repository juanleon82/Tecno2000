# Tecno 2000 - Esta es la primera version

Proyecto de sitio web para una tienda de productos informáticos.

Descripción

Tecno 2000 es un proyecto desarrollado como parte del curso de Front End js.

El sitio presenta productos informáticos como:

 Notebooks
 Monitores
 Teclados
 Mouse
 Auriculares
 Impresoras

Tiene sección de contacto y ubicación.

Tecnologías utilizadas

HTML
CSS
Google Fonts
Font Awesome
